# تطبيق مشترياتي

تطبيق أندرويد بسيط لتسجيل المشتريات يدويًا مع إجماليات اليوم والأسبوع والشهر والسنة.

## بناء APK باستخدام GitHub Actions
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد أو إلى مستودع المشروع.
2. تأكد من وجود الملفات `main.py` و`buildozer.spec` و`.github/workflows/build.yml`.
3. افتح تبويب **Actions**.
4. اختر **Build مشترياتي APK** ثم **Run workflow**.
5. انتظر حتى ينتهي البناء بنجاح.
6. افتح عملية البناء الناجحة، وانزل إلى **Artifacts**، ثم نزّل `moshtarayati-debug-apk`.
7. فك ضغط الملف الذي تم تنزيله لتحصل على ملف APK، ثم ثبّته على هاتف Android.

## ملاحظات
- تُحفظ البيانات داخل مساحة التطبيق على الجهاز نفسه.
- الأسبوع يبدأ يوم الاثنين.
- الفترة اليومية من منتصف الليل إلى منتصف الليل التالي.
- هذه نسخة أولية؛ اختبر البناء على GitHub Actions قبل الاعتماد عليها.
